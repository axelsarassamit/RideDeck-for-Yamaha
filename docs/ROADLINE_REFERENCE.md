In-app artwork now uses the original 1264 x 1264 transparent Canva PNG for each edition, not the 200px preview. Crop coordinates scale with the decoded source size; the launcher remains a native vector adaptation of the same mark.

The full cockpit composition replaces the earlier styling-only update: compact logo header, artwork and metadata grouped together, round transport controls, readable message box with filled action buttons, Standard's separate Maps row, and unboxed bottom controls. The unused portrait GPS summary is removed. Yamaha retains direct Search, Fun ride and Ride tools plus its optional phone modes and separate bike map. Dash uses a framed fitted camera viewport, transparent telemetry, a dedicated Stop action and a secondary Recordings/Setup row. Recording state remains amber and actions retain their existing power/authentication gates.

The mockup illustrates the main screens, not every implemented feature. The functional brief remains authoritative for calls replacing the message box, known-contact announcements, read-only email, supported message replies in the full reader, mirrored controls, System/Light/Dark overrides and host appearance sync, Yamaha routing/provider limits, flat settings, camera capabilities, protected storage, background session authentication and power limits. None of these may be dropped because they are absent from the image. The brief's earlier local-only scope has been superseded by the owner's explicit instruction to implement and push the full design.

Real unavailable states are retained instead of inserting the concept's demonstration track, message, location or camera footage. Button blue is darkened where necessary for white-text contrast. Every colour theme retains readable foregrounds. Generated artwork and phone layout tests do not validate live call audio, motorcycle hardware or long-duration recording reliability.
