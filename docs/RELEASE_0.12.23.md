# RideDeck for Yamaha 0.12.23

The reply review now fills the phone screen. The recipient and messaging app are clearly labelled above a larger, editable 28 sp reply. Send reply is the primary action, with 88 dp tall buttons, 12 dp gaps and large labels. Speak again and Cancel are separated from Send. Portrait keeps controls below the reply; wide landscape keeps them in a separate column beside it. The keyboard starts hidden and the reply content can scroll without pushing the main controls off the portrait screen.

Missing and expired reply controls still retain the draft and expose Copy text and Open conversation. Sending still requires explicit confirmation and uses the existing notification reply action.

Phone verification checks target dimensions, spacing, portrait and landscape layout, editing and local reply delivery. These checks do not establish touch sensitivity with a particular pair of gloves or verify use while riding.
