# RideDeck for Yamaha 0.12.16

Phone interface update for the existing Yamaha app.

- Graphite surfaces, fine borders, restrained corner shapes and consistent menu typography. Setup opens as a compact list of categories with individual icons, summaries and expandable actions. Navigation dialogs use a matching dark theme.
- Music artwork and track details share a single aligned row. Track title, artist and player are separate. The central play/pause control is larger than skip controls. The timeline reflects the selected player's reported position and duration, with unknown progress hidden. A drawn music placeholder appears when the player has no artwork.
- Customization uses readable list rows with a title, current choice and chevron. Existing choices remain saved; Yamaha blue is available as a new accent and is the default when no accent has been selected.
- Large phone guidance, ETA, speed-limit display, music commands, message acknowledgement and existing map/message panel allocation remain in place. This update changes phone presentation, not bike navigation protocols.

Install over the existing Yamaha app to preserve settings and permissions. Native accessory status icons still require verified bike connection/authentication evidence. UI, build and phone verification are recorded separately during delivery; no claim of parked-bike testing follows from CI.
