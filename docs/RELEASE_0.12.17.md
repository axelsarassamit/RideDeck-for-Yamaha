# RideDeck for Yamaha 0.12.17

Includes the cockpit, music and menu redesign from 0.12.16. Actual phone verification found that a long song title could crowd out the artist at the phone's current font scale. This update fits the title to available music-panel height, keeps the artist on its own line and tightens timeline/control spacing. Compact split-screen hides the repeated player label to preserve track details.

Large guidance and the existing map/message panel allocation remain. Native bike navigation and accessory protocols are unchanged. Accessory status icons still need parked-bike connection verification.
