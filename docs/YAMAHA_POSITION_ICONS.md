# Bike position icons

Version 0.12.14 replaces the blue position dot with original top-view vector artwork. The same renderer supplies the phone picker preview, the phone map and the streamed bike map. Model and colour choices are saved locally and take effect on subsequent map frames without reconnecting. The GPS coordinate remains the icon centre; rotation is rider bearing relative to map camera bearing.

Styles: XMAX, NMAX, MT-07, MT-09, XSR900, XSR900 GP, R9 and TRACER 7. Colours: Yamaha blue, black, red, grey, white, green, yellow and purple. Default: XMAX / Yamaha blue. White edging and a forward pointer preserve visibility on the route line and dark roads.

Appearance selection does not change the bike connection protocol or certify additional hardware. RideDeck live testing is with the user's XMAX 2024, 480 x 234 display. Other StreetCross families use the existing 480 x 240 map path; native turn views on those families remain unverified.

Model-family scope follows Yamaha's July 2025 connectivity list, which places these families under StreetCross for specified years/trims. It excludes Motorize-only TMAX, NIKEN and TRACER 9 from this icon selector. Regional/year/trim differences still apply.
