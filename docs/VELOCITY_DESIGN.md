# Shared RideDeck design

The approved Velocity R and Roadline identity now appears in the launcher, cockpit and startup sequence. In-app artwork has transparent margins. Shared graphite, navy, blue, white and amber colours have Light and Dark treatments; System and explicit appearance choices remain available.

Standard retains external navigation. Yamaha keeps built-in navigation and a separate motorcycle display; Music is the default phone panel only when no saved panel preference exists. Map and Turn arrows remain selectable. Idle phone guidance no longer consumes message space; active route guidance remains available.

Both hosts retain a readable message box with Read aloud and Seen / next, even when empty or access is missing. Calls temporarily replace that box. Email remains read-only. Dash keeps transparent speed, GPS and stabilisation text over unchanged camera footage, with an amber recording action.

Existing shared Setup categories and product-specific sections remain in place. Production application IDs, signer checks and companion protocols are preserved. New artwork does not establish bike hardware, call audio or recording reliability. Physical layout checks cover Light/Dark and portrait/landscape; live bike and call-audio checks remain separate.
