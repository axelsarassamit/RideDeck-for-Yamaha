# RideDeck for Yamaha 0.12.21

Includes the menu fixes and four clearly labelled cockpit readouts from 0.12.20: Time, Time remaining, Arrival time, Distance remaining. Each appears once per cycle. Distance includes one decimal and km units.

The live phone check uncovered MapLibre's automatic snapshot attribution overlay in addition to RideDeck's credits row. Snapshot logo/attribution overlays are now disabled because RideDeck renders the required MapTiler logo and MapTiler/OpenStreetMap attribution itself: a single tappable row on the phone and a footer on each bike map frame. Turn guidance remains visible.

Phone menu checks verified Reply method, Color theme, mount, placement and voice-guidance persistence while restoring original choices. Destination search exposes saving as Favorite, Home or Work. Invalid Home/Work coordinates remain in the form for correction. Physical-bike commands and accessory authentication still require parked-bike verification.
