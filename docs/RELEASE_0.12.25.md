# RideDeck for Yamaha 0.12.25

The Android launcher icon now uses a blue background, white RideDeck mark and red Yamaha Motor badge. The badge preserves the emblem from the existing checked-in Motor artwork. Android adaptive icons support round and rounded-square launcher masks.

The cockpit keeps its existing RideDeck and Yamaha logos. Standard RideDeck is unchanged. Navigation, parking, message reply and music behavior are unchanged from 0.12.24.

Validation: Android resource compilation, packaged application icon verification and desktop previews at launcher sizes. Signed artifact and phone verification are recorded separately.
